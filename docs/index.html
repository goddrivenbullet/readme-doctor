readme-doctor

Why nobody is using your repository — checked in one command.

A README is the product page. This audits the things that decide whether someone installs it: a working install line, a visible demo, a license, resolvable links, closed code fences and a first paragraph that says what the thing does.

View on GitHub npm README

What it does

Eleven checksInstall, usage, license, badges, links, fences, placeholders.
Broken link detectionRelative links are resolved against the repository.
A scoreso two READMEs can be compared.
Concrete fixesnot a checklist, the next line to write.

Usage

Audit a repositoryreadme-doctor .
Machine readablereadme-doctor . --json

How it works

  1. The README is parsed into sections so the biggest parts can be pointed at.
  2. Relative links are resolved on disk; code fences are counted for balance.
